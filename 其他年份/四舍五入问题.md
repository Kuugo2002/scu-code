# 四舍五入问题

## 题目描述

输入 3 个正整数 a, b, c，输出 a/b 的小数形式，精确到小数点后 c 位（注意最后一位的四舍五入问题）。

**约束条件：**
- 2 < a, b < 1000000
- 2 < c < 1000
- 注意本题小数保留范围

## 输入描述

第 1 行是一个整数 n，表示随后有 n 组数据。每组数据占一行，输入正整数 a, b, c，用空格隔开。

## 输出描述

对每组数据，计算并输出 a/b 的小数形式，保留小数点后 c 位，并换行。

## 输入样例

```
3
2 3 20
2 6 10
6 7 3
```

## 输出样例

```
0.66666666666666666667
0.3333333333
0.857
```
