# 元素交换

## 题目描述

给定一个长度为 n (n ≤ 100) 的数组，将其中第偶数位置的元素与前一个元素交换。

**注意：** 位置从 1 开始计数，即第 2、4、6... 位的元素需要与其前一位交换。

## 输入格式

- 第一行：一个整数 n，表示数组长度
- 第二行：n 个整数，表示数组元素

## 输出格式

- 一行：交换后的数组元素，用空格分隔

## 样例

### 输入
```
5
1 2 3 4 5
```

### 输出
```
2 1 4 3 5
```

## 示例说明

原始数组：`[1, 2, 3, 4, 5]`

- 位置 2 的元素 `2` 与位置 1 的元素 `1` 交换 → `[2, 1, 3, 4, 5]`
- 位置 4 的元素 `4` 与位置 3 的元素 `3` 交换 → `[2, 1, 4, 3, 5]`
- 位置 5 是奇数位置，不交换

最终结果：`[2, 1, 4, 3, 5]`

## 约束条件

- 1 ≤ n ≤ 100
