# 单链表节点交换

## 题目描述

输入一个单链表,将奇数位置上的节点与偶数位置上的节点进行交换,然后输出交换之后的链表。

## 输入描述

- 第一行:输入一个整数 `n`(`n < 100`),表示节点数量
- 第二行:输入 `n` 个整数,表示链表中的节点值

## 输出描述

输出交换后的链表,节点之间用空格分隔。

## 示例

### 输入
```
5
1 2 3 4 5
```

### 输出
```
2 1 4 3 5
```

## 说明

原始链表:1 → 2 → 3 → 4 → 5

交换过程:
- 位置1(值为1)与位置2(值为2)交换
- 位置3(值为3)与位置4(值为4)交换
- 位置5(值为5)无配对节点,保持不变

交换后链表:2 → 1 → 4 → 3 → 5
