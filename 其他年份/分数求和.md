# 分数求和

## 题目描述

有一分数序列：

$$\frac{2}{1}, \frac{3}{2}, \frac{5}{3}, \frac{8}{5}, \frac{13}{8}, \frac{21}{13}, ...$$

求出这个数列的前 N 项之和，保留两位小数。

### 数列规律

观察分子和分母的规律：
- **分子**：2, 3, 5, 8, 13, 21, ... （斐波那契数列）
- **分母**：1, 2, 3, 5, 8, 13, ... （斐波那契数列）

每一项的分子是前两项分子之和，分母也是前两项分母之和。

---

## 输入描述

```
N
```

其中 N 表示要求前 N 项的和。

---

## 输出描述

```
数列前N项和
```

输出结果保留两位小数。

---

## 样例

### 输入

```
10
```

### 输出

```
16.48
```
