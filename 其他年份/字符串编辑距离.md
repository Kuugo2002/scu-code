# 字符串编辑距离

## 题目描述

给定两个字符串 A 和 B,求字符串 A 至少经过多少步字符操作变成字符串 B。

### 问题分析

我们以一个例子来分析,比如将 `eat` 变成 `tea`。对于第一个字符,由于 `e != a`,所以要想让这两个字符相等,有三种可以选择的办法:

1. **修改字符**:将 `e` 直接变成 `a`,需要走 1 步
2. **插入字符**:在 `e` 的前面插入 `a`,也需要走 1 步
3. **删除字符**:将 `e` 删除,然后比较后面的字符与 `a`,也需要走 1 步

## 输入描述

输入字符串 A 和 B(长度小于 1000)

## 输出描述

输出最少经过多少步可以将 A 变成 B

## 样例

**输入:**
```
abcd
abc
```

**输出:**
```
1
```
