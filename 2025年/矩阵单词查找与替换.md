# 矩阵单词查找与替换

## 题目描述

给定一个 `n × m` 的字符矩阵，要求在矩阵中找出所有连续排列的字符串 **"hello"**。满足以下条件：

1. **"hello"** 的 5 个字符必须沿**单一方向**连续排列（方向包括：上、下、左、右、左上、右上、左下、右下，共 8 个方向）；
2. 同一个 **"hello"** 的 5 个字符必须严格沿同一个方向，且每个字符的位置在矩阵范围内。

找到所有符合条件的 **"hello"** 后，将矩阵中**不属于任何一个 "hello"** 的字符替换为 `*`，并输出处理后的矩阵。若一个位置同时属于多个 **"hello"**，仍保留原字符。

---

## 输入描述

- 第一行输入两个整数 `n` 和 `m`（`1 ≤ n, m ≤ 100`），表示矩阵的行数和列数。
- 接下来 `n` 行，每行输入一个长度为 `m` 的字符串，表示字符矩阵（字符串仅包含小写英文字母）。

## 输出描述

输出处理后的 `n` 行字符矩阵，每行对应原矩阵的行：
- 属于任意一个 **"hello"** 的字符保留原字符
- 其余字符替换为 `*`

---

## 样例

### 输入
```
6 7
helloab
xhelloc
yzhello
hxxxxxx
ehellod
lehello
```

### 输出
```
hello**
*hello*
**hello
*******
*hello*
**hello
```
