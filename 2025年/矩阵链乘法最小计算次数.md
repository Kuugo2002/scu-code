# 矩阵链乘法最小计算次数

## 题目描述

给定 $n$ 个矩阵构成的矩阵链 $A_1, A_2, \dots, A_n$，其中矩阵 $A_i$ 的维度为 $p_{i-1} \times p_i$（$1 \leq i \leq n$）。矩阵乘法满足结合律，不同的相乘顺序会导致不同的标量乘法次数（矩阵乘法的核心计算量）。

例如，若矩阵 $A$ 为 $m \times k$ 维，矩阵 $B$ 为 $k \times n$ 维，则 $A \times B$ 的标量乘法次数为 $m \times k \times n$，结果矩阵为 $m \times n$ 维。

请设计算法，计算出将所有矩阵完全相乘的最小标量乘法次数。

## 输入描述

- 第一行输入一个整数 $n$（$1 \leq n \leq 100$），表示矩阵链中矩阵的个数；
- 第二行输入 $n+1$ 个正整数 $p_0, p_1, \dots, p_n$（$1 \leq p_i \leq 1000$），依次表示矩阵链的维度序列，其中矩阵 $A_i$ 的维度为 $p_{i-1} \times p_i$。

## 输出描述

输出一个整数，表示矩阵链乘法的最小标量乘法次数。

## 样例

### 输入样例
```
2
1 2 3
```

### 输出样例
```
6
```
