# 有向图最长路径问题

## 题目描述

给定一个有向图，包含 `n` 个节点和 `m` 条有向边，每条边带有一个整数权重（可正可负）。指定起点 `S` 和终点 `T`，请计算从 `S` 到 `T` 的最长路径长度。

若存在以下情况之一，输出 `-1`：
1. 从 `S` 无法到达 `T`
2. 从 `S` 到 `T` 的路径中包含环（导致最长路径长度无穷大）

## 输入格式

第一行包含四个整数 `n`、`m`、`S`、`T`，分别表示：
- **节点数** `n`（1 ≤ n ≤ 1000）
- **边数** `m`（1 ≤ m ≤ 5000）
- **起点** `S`（1 ≤ S ≤ n）
- **终点** `T`（1 ≤ T ≤ n）

> 节点编号从 1 到 n

接下来 `m` 行，每行包含三个整数 `u`、`v`、`w`，表示一条从节点 `u` 到节点 `v` 的有向边，权重为 `w`（-100 ≤ w ≤ 100）。

## 输出格式

输出一个整数，表示 `S` 到 `T` 的最长路径长度；若满足输出 `-1` 的条件，直接输出 `-1`。

## 样例

### 输入
```
4 4 1 4
1 2 3
1 3 5
2 4 5
3 4 2
```

### 输出
```
8
```

### 样例说明

从节点 1 到节点 4 有两条路径：
- 路径 1→2→4：长度为 3 + 5 = 8
- 路径 1→3→4：长度为 5 + 2 = 7

因此最长路径长度为 **8**。
