# 最大数组距离

## 题目描述

给定 $m$ 个升序排列的整数数组,你需要从两个**不同的数组**中各选择一个整数,计算这两个数的距离(距离定义为两数差的绝对值 $|a - b|$)。

请你找出所有可能选择方案中的**最大距离**。

---

## 输入格式

第一行输入一个整数 $m$($2 \leq m \leq 10^4$),表示数组的个数。

接下来 $m$ 行,每行描述一个数组:
- 每行的第一个整数 $n_i$($1 \leq n_i \leq 10^3$),表示第 $i$ 个数组的元素个数
- 随后输入 $n_i$ 个整数 $a_{i1}, a_{i2}, \dots, a_{in_i}$($-10^9 \leq a_{ij} \leq 10^9$),表示第 $i$ 个数组的元素
- **保证数组严格升序排列**

---

## 输出格式

输出一个整数,表示所有符合条件的数对的最大距离。

---

## 数据范围

- 数组总数 $m$: $2 \leq m \leq 10^4$
- 单个数组长度 $n_i$: $1 \leq n_i \leq 10^3$
- 所有数组的元素总数之和不超过 $10^7$
- 数组元素取值范围: $-10^9 \leq a_{ij} \leq 10^9$

---

## 样例

### 输入
```
3
3 1 4 6
2 2 5
4 -3 0 7 10
```

### 输出
```
9
```

### 样例说明

从第 1 个数组选择 $1$,从第 3 个数组选择 $10$,距离为 $|1 - 10| = 9$,这是所有可能选择中的最大距离。
