# 显示柱状图

## 题目描述

根据输入的数字和符号生成相应的柱状图显示。

**注意：** 输出样例中的下划线 `_` 实际表示空格，真实输出应如下图所示：

```
    b
  + b
  + b +
a + b +   +
-----------
        +
        +
```

## 输入描述

每个输入包含一个测试用例：
- 第一个整数 `n`，表示随后有 `n` 组数据
- 每组数据由一个数字和一个字符组成，每组数据之间用空格分隔
- 数字代表柱状图的高度
- 字母代表该柱使用的画图符号
- 如果数字后没有字母，默认该柱的画图符号使用加号 `+`

## 输出描述

- 每个柱之间用 1 个空格间隔
- 图的空白处用空格填充
- 用减号 `-` 表示 x 轴
- 正数柱状向上，负数柱状向下
- **注意：** 因为显示原因，下方样例第一行用下划线来代替空格占位，实际输出是空格！

## 输入样例

```
6 1a 3 4b 2 -2 1
```

## 输出样例

```
____b
  + b
  + b +
a + b +   +
-----------
        +
        +
```
